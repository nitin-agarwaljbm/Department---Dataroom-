Project Templates
A template is a charter of KPIs and activities. Each new project follows one template, and its T0 date drives every date in the charter. Create a template from an Excel sheet in the charter format.
TemplateKPIsActivities
Create a template from Excel
Columns (first row): Sl, Type, Event, Title, Teams, Owner, Reviewer, Contributors, Formula. Type is KPI or Activity (activities sit under the KPI above them). Owner, Reviewer and Contributors are team names. Formula is the event it follows plus days, e.g. A8 + 9d, T0 + 30d, T7 - 60d; the first KPI (T0) uses T0 date. Other columns are ignored. Team Roster
The person for each team. When a project is created, every activity's Owner, Reviewer and Contributor team (from its template) is replaced by that team's person here; a team with nobody set shows "-" on the project. Existing projects change only when you use "Fill blank owners" (fills the blanks only) or "Reset all owners" (re-applies this list to every activity) on that project. The project manager is never used as an automatic owner or reviewer.
